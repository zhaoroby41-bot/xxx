# 抖音矩阵作品内容分析 — 提示词模板

> 用途：输入各账号矩阵的月度运营数据，生成一份对品牌方有决策价值的抖音矩阵洞察报告。  
> 适用平台：抖音（短视频为主）

---

## 提示词模板

```
你是一位资深的抖音矩阵运营分析师，擅长从经销商/门店矩阵账号的短视频数据中提炼出对品牌方有决策价值的洞察。你深谙抖音推荐算法逻辑（完播率→互动率→分享率的递进权重机制）。

请基于以下原始数据，生成一份结构化的「抖音矩阵作品内容分析月报」，面向品牌方市场部/数字营销负责人阅读。

## 前提条件
爆款作品的定义：读取Excel中的"播放量"超过5000，或者"播放量"超过3000 且 ("点赞量" + "评论量" + "收藏量" + "分享量") 超过200。满足任一条件的属于爆款作品。

审核状态说明：
- "公开"：正常公开可见
- "自见"：仅作者可见（疑似被限流/审核未通过）
- "不适宜公开"：被平台判定违规
- "需优化"：平台建议修改后重新发布

## 输出要求

请按以下五个维度输出分析，每个维度需包含「数据事实 + 归因分析 + 行动建议」三层：

---

### 维度一：矩阵整体数据表现

1. **核心指标环比变化**（总播放量及环比增长%、总互动量及环比增长%、粉丝净增及环比增长%、作品总数、爆款作品数、活跃账号数），环比指标用箭头（📈🔻➡️）标注涨跌百分比
   - 环比口径说明：按「月度」对比（最近完整月 vs 上月）
2. **抖音核心漏斗指标**：
   - 2s留存率 → 5s完播率 → 完播率 → 互动率 → 分享率
   - 标注漏斗各环节的转化率及环比变化
   - 识别漏斗中的最大流失环节
3. **指标异动归因**（为什么涨/跌？是内容策略变化、平台算法波动、还是外部事件驱动？）
4. **梯队效能分布**：将经销商按表现分为 S/A/B/C 四档，给出各档数量与典型代表

---

### 维度二：矩阵生态健康度

1. **发布行为分析**：
   - 识别「稳定输出型」vs「脉冲爆发型」vs「低频/停更」账号，给出代表及特征
   - 每类账号需量化关键指标对比：均播放量、合规率（公开占比）、效率倍数差异
   - 计算发布频率方差，评估矩阵整体稳定性
   - 标注本期停更/低频账号数量及占比

2. **账号健康度评分**（满分100分）：
   按以下规则为每个账号计算健康度评分：
   - 发布稳健(20分) = min(月发布量 ÷ 矩阵月均发布量, 1) × 20
   - 合规审核(25分) = 公开作品数 ÷ 总发布数 × 25
   - 流量表现(30分) = min(均播放量 ÷ 矩阵均播放量, 1) × 30
   - 内容质量(25分) = min(均完播率 ÷ 矩阵均完播率12.6%, 1) × 25
   - 各项最低0分，剔除完播率>100%的异常数据后计算
   - 矩阵均值口径统一为「作品级均值」（所有有效作品直接求平均，非账号级均值的均值）
   - 输出Top 15账号的评分明细（堆叠柱状图展示各维度得分），图表下方附评分规则说明
   - 输出全矩阵健康度评分列表：包含全部账号的总分和等级（优秀🟢/良好🔵/亚健康🟡/需辅导🔴），按分数降序排列
   - 输出全矩阵月播放量排名列表：包含全部账号的发布条数和月播放量，按播放量降序排列
   - 健康度分档标准：优秀(80-100分)、良好(65-80分)、亚健康(50-65分)、需辅导(<50分)
   - 布局：第一行左=健康度评分Top15柱状图+规则，右=全账号健康度评分可滚动列表；第二行左=各账号月播放量vs矩阵均值线(Top15)，右=全账号月播放量可滚动列表

3. **审核风控分析**：
   - 统计"自见"/"不适宜公开"/"需优化"状态的作品数量及占比
   - 按笔记类型分析异常率（哪类内容最容易触发审核）
   - 按日期分析异常集中度（是否存在批量发布触发风控）
   - 按账号分析异常率（哪些账号是高危账号）
   - 对比异常作品 vs 正常作品的均播放量，量化流量损失
   - 给出数据结论：审核问题集中在哪些维度（品类/日期/账号）

3. **内容同质化检测**：
   - 是否存在大面积素材搬运导致限流？
   - 音视频指纹重复率评估（相同BGM + 相同画面结构）
   - 给出受影响账号数量及播放损失估算

4. **优化建议**：针对审核风控和同质化问题给出具体可执行方案（二次剪辑、真人出镜、原创配音、差异化封面等）

---

### 维度三：内容监测与爆款归因

1. **完播率深度分析**：
   - 高完播率作品的共性特征（时长、开头节奏、内容结构、BGM选择）
   - 低完播率作品的问题诊断（2s跳出率高 → 封面/开头问题；中途流失 → 内容节奏问题）
   - 完播率与播放量的相关性分析

2. **爆款特征决策树**：
   - 从 Top 20 爆款中提取高频共性特征（视频时长、开头3秒设计、封面风格、BGM类型、出镜方式、标签策略、发布时间）
   - 输出「抖音爆款概率公式」：[特征A] + [特征B] + ... = 爆款率提升 X%
   - 给出各特征的贡献权重

3. **抖音爆款逻辑**：
   - 抖音公式：[3秒视觉/悬念抓手] + [高颜值真人出镜] + [热门BGM] + [信息密度节奏] → 完播率驱动推荐
   - 给出本期验证有效的具体内容创作模板
   - 区分「推荐流量型」vs「搜索流量型」爆款的不同特征

4. **体裁效能对比**：
   - 各体裁（1min-视频/1-3min视频/3-5min视频/5min+视频/图文）的平均播放量、完播率、互动率对比
   - 给出最优体裁推荐及适用场景

---

### 维度四：用户反馈信号与心智洞察

1. **互动结构分析**（通过互动比例判断用户意图）：
   - 高收藏率作品 → 用户处于「信息收集/决策前期」，内容有实用价值
   - 高评论率作品 → 用户有疑问或购买意向，话题引发讨论
   - 高分享率作品 → 内容有社交货币属性，适合裂变传播
   - 给出本期各类型占比，判断矩阵内容当前触达的用户决策阶段

2. **主页访问与粉丝转化分析**：
   - 高主页访问量作品的共性（什么内容让用户想看更多？）
   - 主页访问→粉丝转化率分析
   - 高粉丝增量作品的特征提取

3. **笔记类型效能排名**：
   - 各笔记类型的播放效率、互动效率、粉丝转化效率排名
   - 识别高ROI内容方向和低效内容方向

4. **行动建议**：
   - 基于互动结构，下期内容应侧重哪类互动目标
   - 基于笔记类型效能，调整内容配比建议

---

### 维度五：下月行动指南

按不同业务目标分别给出具体的内容建议，每个目标需明确：推荐的执行主体（哪个账号/哪类账号）、具体内容选题举例、预期效果。

1. **目标一：播放量突破**
   - 推荐主体：适合执行此目标的账号
   - 内容建议：具体选题举例（标题+形式+时长+发布时间）
   - 完播率优化要点：开头3秒设计、节奏把控、结尾钩子
   - 预期效果：基于本期数据的播放量估算

2. **目标二：粉丝增长**
   - 推荐主体：适合执行此目标的账号
   - 内容建议：具体选题举例（系列化内容、人设打造方向）
   - 主页引导策略：如何从单条爆款转化为账号粉丝
   - 预期效果：基于本期数据的粉丝转化率估算

3. **目标三：搜索流量布局**
   - 推荐主体：适合执行此目标的账号
   - 内容建议：具体选题举例（需命中的搜索关键词）
   - SEO优化要点：标题关键词、话题标签、评论区引导
   - 预期效果：长尾流量持续周期估算

4. **目标四：异常账号修复**
   - 审核异常账号的修复方案（解除"自见"状态的操作步骤）
   - 低效账号的内容方向调整建议
   - 每个账号的具体问题诊断和修复方案

5. **发布节奏与热点借势**
   - 最佳发布时间段（基于本期爆款发布时间分析）
   - 最优视频时长建议（基于完播率数据）
   - 下期可借势的平台热点/挑战赛/节日/品牌活动

## 输出格式要求

- 输出为单文件 HTML 报告（自包含 CSS + Chart.js 图表脚本）
- 深色主题，渐变背景（#0f0c29 → #1a1a2e → #16213e），抖音品牌色（#fe2c55 主色 + #25f4ee 辅色）为主色调
- 每个维度用 Emoji 标题区分，层次清晰
- 核心 KPI 使用卡片式布局（带顶部渐变色条 + 进度条 + 环比标签），5张卡片一行
- 新增「完播漏斗」可视化：2s留存率 → 5s完播率 → 完播率 → 互动率 → 分享率（阶梯式漏斗）
- 数据点用表格呈现，趋势用箭头（📈🔻➡️）标注，环比指标内联显示不单独占行
- 归因分析使用 attribution-block 样式（青色边框卡片 + factor 标签高亮关键因素）
- 爆款公式使用 formula-box 样式（渐变背景 + tag 标签）
- 行动指南使用 action-list 样式（编号圆圈 + 标题 + 描述）
- 图表使用 Chart.js 4.4.0（折线图/饼图/雷达图/柱状图/气泡图），通过 CDN 引入
- 图表设计注意事项：不同量级的指标不要放在同一Y轴，应改用环比增长率（%）统一量纲，或拆分为独立图表
- 行动建议必须具体可执行（谁、做什么、什么标准），避免"提升内容质量"这类空话
- 全文控制在 3000 字以内，品牌方高管能在 5 分钟内读完
- 语言风格：专业但不学术，数据驱动但有温度，像一位资深顾问在做汇报
- 维度五「下月行动指南」是必须包含的维度，不可省略
```

## 使用说明

1. 将「输入数据」部分替换为每期的实际数据（从Excel「抖音作品数据库」sheet读取）
2. 如果某些数据暂时缺失（如搜索指数、竞品数据），可在对应位置标注「本期暂无数据，跳过该子项」
3. 可根据品牌方关注重点调整五个维度的权重或增删子项
4. 首次使用建议先用一个月完整数据跑一遍，根据输出质量微调输入数据的颗粒度
5. 抖音数据特别关注「完播率」和「5s完播率」，这是抖音推荐算法的核心权重指标

## 抖音 vs 小红书 分析差异对照

| 维度 | 小红书 | 抖音 |
|------|--------|------|
| 核心流量指标 | 曝光量（阅读数） | 播放量 |
| 算法核心权重 | 互动率（赞藏评转） | 完播率 → 互动率 |
| 内容生命周期 | 搜索长尾（可持续数月） | 推荐短爆（24-72h为主） |
| 爆款驱动因素 | 信息密度 + 搜索关键词 | 3秒抓手 + 完播率 + BGM |
| 同质化风险 | 图文MD5查重 + 文案去重 | 视频指纹检测 + 音频查重 |
| 审核机制 | 限流（小黑屋） | 自见/不适宜公开/需优化 |
| 粉丝转化路径 | 收藏→关注 | 主页访问→关注 |
| 最优内容时长 | 图文为主 | 1min以内短视频 |

## 模板设计理念

| 设计原则 | 说明 |
|---------|------|
| 完播率优先 | 抖音算法以完播率为第一权重，所有分析围绕完播率展开 |
| 漏斗思维 | 封面点击→5s留存→完播→互动→分享，逐层分析流失点 |
| 数据事实先行 | 每个结论必须有数据支撑，避免主观臆断 |
| 归因不止于表象 | 不只说"涨了/跌了"，要说清楚"为什么" |
| 行动导向 | 每个维度最终落到"下一步做什么"，品牌方看完就能决策 |
| 审核风控意识 | 抖音审核严格，需持续监控"自见"等异常状态 |
