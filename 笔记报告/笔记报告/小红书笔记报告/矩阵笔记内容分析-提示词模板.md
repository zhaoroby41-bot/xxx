# 矩阵笔记内容分析 — 提示词模板

> 用途：输入各账号矩阵的周度运营数据，生成一份对品牌方有决策价值的洞察报告。  
> 适用平台：小红书 / 抖音 / 双平台矩阵。

---

## 提示词模板

```
你是一位资深的社交媒体矩阵运营分析师，擅长从经销商/门店矩阵账号的内容数据中提炼出对品牌方有决策价值的洞察。

请基于以下原始数据，生成一份结构化的「矩阵笔记内容分析周报」，面向品牌方市场部/数字营销负责人阅读。

---
##前提条件
爆款笔记的定义（满足以下任一条件即为爆款，两个条件取OR并集）：
- 条件一：「累计阅读数」> 1000
- 条件二：「累计阅读数」+「累计评论数」+「累计收藏数」> 1000

⚠️ 筛选时必须同时检查两个条件，不可仅用条件一筛选而遗漏条件二。
典型案例：某笔记阅读782、评论253、收藏217，阅读未达1000但三项合计1252>1000，应判定为爆款。

## 输入数据
 输入数据是从Excel模版中读取。
【平台】：{小红书}
【分析周期】：{取“笔记发布时间”字段}
【矩阵规模】：{取“作者昵称”去重}
【笔记发布量】：{模版中的笔记条数}
【总曝光量】：{取累计阅读数}
【总互动量】：{点赞/评论/分享/收藏合计}
【粉丝净增】：{新增粉丝数}
【矩阵总新增粉丝量】：{所有笔记的新增粉丝数累计}
【Top 20 爆款笔记数据】：（标题、曝光、互动量、赞/藏/评/转各项数值、发布时间、内容类型、封面特征等）
【各账号本周数据明细】：（账号名、发布数、曝光、互动、粉丝增量等）
【平台处罚/限流情况】：（如有，需要有直接证据或者间接推理举证被平台处罚）
【本周营销事件/活动】：（如有降价、车展、新品发布等）

## 输出要求

请按以下五个维度输出分析，每个维度需包含「数据事实 + 归因分析 + 行动建议」三层：

---

### 维度一：矩阵整体数据表现

1. **核心指标环比变化**（总曝光量及环比增长%、总互动量及环比增长%、粉丝净增及环比增长%、笔记总数、爆款笔记数、活跃账号数），环比指标用箭头（📈🔻➡️）标注涨跌百分比，不单独占用行内空间
   - 环比口径说明：on line 渠道按「双周」对比（拉取日倒推2周）；mono 渠道按「月度」对比（最近完整月 vs 上月）
2. **指标异动归因**（为什么涨/跌？是内容策略变化、平台算法波动、还是外部事件驱动？）
3. **梯队效能分布**：将经销商按表现分为 S/A/B/C 四档，给出各档数量与典型代表，标注本周达标率

---

### 维度二：矩阵生态健康度

1. **全矩阵账号数据总览表**：在维度二的图表区域中，与「各账号发布频率分布」柱状图并排（chart-row 同一行），输出一张完整的账号数据总览表格，包含以下列：
   - 序号（#）
   - 账号名称
   - 发布数量（X条）
   - 均阅读数（按均阅读降序排列，S级账号的均阅读数字用绿色 #00e676 高亮）
   - 梯队标签（S/A/B/C，使用对应颜色的 badge 样式）
   - 表格容器设置固定高度（600px）、最大高度600px，并启用纵向滚动（overflow-y:auto），标题格式为「全矩阵账号数据总览（X家）」

2. **发布行为分析**：
   - 识别「稳定输出型」vs「脉冲爆发型」账号，给出代表及特征
   - 计算发布频率方差，评估矩阵整体稳定性
   - 标注本周停更/低频账号数量及占比

3. **内容同质化检测**：
   - 小红书端：是否存在大面积素材雷同导致流量折叠？影响范围？
   - 抖音端：是否存在搬运限流？音视频指纹重复率？
   - 给出受影响账号数量及曝光损失估算

4. **优化建议**：针对同质化问题给出具体可执行的差异化方案（首段重写、封面重绘、真人实景解说、二次剪辑等）

---

### 维度三：内容监测与爆款归因

1. **爆文生命周期分析**：
   - 区分「长尾复利型」（进入搜索推荐池，发布7天后仍有稳定流量）vs「一波流型」（前3小时后断崖下跌）
   - 给出典型案例及曝光衰减曲线特征描述
   - 分析触发长尾的内容特征（搜索关键词命中、信息密度、实用性等）

2. **爆款特征决策树**：
   - 从 Top 20 爆款中提取高频共性特征（标题结构、封面元素、发布时间、标签策略、情绪符号等）
   - 输出「爆款概率公式」：[特征A] + [特征B] + ... = 爆款率提升 X%
   - 给出各特征的占比权重

3. **双平台差异化爆款逻辑**：
   - 小红书公式：[痛点词] + [数字盘点] + [大量Emoji] → 信息密度驱动收藏
   - 抖音公式：[3秒视觉抓手] + [高颜值店员/真人出镜] + [热门BGM] → 视听冲击驱动完播
   - 给出各平台本周验证有效的具体内容创作模板

---

### 维度四：用户反馈信号与心智洞察

> 数据来源：笔记互动指标（赞/藏/评/转的比例结构）、搜索关键词趋势、互动数变化趋势

1. **互动结构分析**（通过互动比例判断用户意图）：
   - 高收藏率笔记 → 用户处于「信息收集/决策前期」，内容有干货价值
   - 高评论率笔记 → 用户有疑问或购买意向，话题引发讨论
   - 高转发率笔记 → 内容有社交货币属性，适合裂变传播
   - 给出本周各类型占比，判断矩阵内容当前触达的用户决策阶段

2. **内容情绪倾向推断**（基于互动数据间接判断）：
   - 高互动但低收藏 → 可能引发争议或负面讨论
   - 高收藏低评论 → 内容实用但缺乏互动钩子
   - 互动量突然下跌的笔记 → 可能触发平台审核或用户反感
   - 标注需要关注的异常笔记

3. **搜索热度与品牌心智**（如平台提供搜索指数/关联词）：
   - 本周品牌相关搜索词变化趋势
   - 用户主动搜索的关联需求词（反映真实购买动机）
   - 搜索词与矩阵内容的匹配度评估

4. **竞品内容对比信号**（可选，如能获取同品类公开数据）：
   - 同品类竞品矩阵的爆款方向
   - 我方内容在用户心智中的差异化定位是否清晰

5. **行动建议**：
   - 基于互动结构，下周内容应侧重哪类互动目标（种草收藏 vs 引发讨论 vs 社交裂变）
   - 识别高评论率笔记的共性，提炼可复用的「互动钩子」话术

---

### 维度五：下周行动指南

按不同业务目标分别给出具体的内容建议，每个目标需明确：推荐的执行主体（哪个账号/哪类账号）、具体内容选题举例、预期效果。

1. **目标一：涨粉**
   - 推荐主体：适合执行此目标的账号
   - 内容建议：具体选题举例（标题+形式+发布时间）
   - 预期效果：基于本期数据的粉丝转化率估算

2. **目标二：品牌曝光**
   - 推荐主体：适合执行此目标的账号
   - 内容建议：具体选题举例
   - 预期效果：基于本期爆款数据的曝光量估算

3. **目标三：SEO长尾价值（搜索流量）**
   - 推荐主体：适合执行此目标的账号
   - 内容建议：具体选题举例（需命中的搜索关键词）
   - 预期效果：长尾流量持续周期估算

4. **目标四：异常账号修复**
   - 需要单独辅导的低效账号清单
   - 每个账号的具体问题诊断和修复方案

5. **发布节奏与热点借势**
   - 最佳发布时间段（基于本期爆款发布时间）
   - 下周可借势的平台热点/节日/品牌活动

---

## 输出格式要求

- 输出为单文件 HTML 报告（自包含 CSS + Chart.js 图表脚本）
- 深色主题，渐变背景（#0f0c29 → #1a1a2e → #16213e），小红书品牌红 (#ff2442) 为主色调
- 每个维度用 Emoji 标题区分，层次清晰
- 核心 KPI 使用卡片式布局（带顶部渐变色条 + 进度条 + 环比标签）
- 数据点用表格呈现，趋势用箭头（📈🔻➡️）标注，环比指标内联显示不单独占行
- 归因分析使用 attribution-block 样式（蓝色边框卡片 + factor 标签高亮关键因素）
- 爆款公式使用 formula-box 样式（渐变背景 + tag 标签）
- 行动指南使用 goal-card 样式（按目标分卡片，每卡片含推荐主体/内容选题/预期效果）
- 发布节奏使用 action-list 样式（编号圆圈 + 标题 + 描述）
- 图表使用 Chart.js 4.4.0（折线图/饼图/雷达图/柱状图/散点图），通过 CDN 引入
- 图表设计注意事项：不同量级的指标不要放在同一Y轴（如曝光量万级 vs 笔记数百级），应改用环比增长率（%）统一量纲，或拆分为独立图表
- 维度一必须包含一张「矩阵指标环比增长率趋势」折线图（三条线：曝光/笔记数/互动，共用Y轴，单位为%，Y轴刻度步长20%），不要单独的曝光趋势或互动趋势绝对值图
- 维度一不要包含「X月 vs Y月 环比增长率对比」柱状图和「经销商梯队效能分布」图表（梯队信息用文字或表格呈现即可）
- 维度二必须包含一张「账号效能分布」散点图（X轴=发布数量，Y轴=均阅读数，按S/A/B/C梯队分色标注），容器设置 min-height:500px、grid-column: 1 / -1（跨两列）并使用 flex 布局撑满
- 维度二必须包含一张「全矩阵账号数据总览表」，与「各账号发布频率分布」柱状图并排放置在同一 chart-row 中，使用 data-table 样式，容器固定高度600px、max-height:600px、overflow-y:auto 实现滚动，S级账号的均阅读数值使用绿色(#00e676)高亮，梯队列使用对应颜色的 badge（badge-s/badge-a/badge-b/badge-c）
- 行动建议必须具体可执行（谁、做什么、什么标准），避免"加强内容质量"这类空话
- 全文控制在 3000 字以内，品牌方高管能在 5 分钟内读完
- 语言风格：专业但不学术，数据驱动但有温度，像一位资深顾问在做汇报
- 维度五「下周行动指南」是必须包含的维度，不可省略
```

---

## 使用说明

1. 将「输入数据」部分替换为每周的实际数据
2. 如果某些数据暂时缺失（如搜索指数、竞品数据），可在对应位置标注「本周暂无数据，跳过该子项」
3. 可根据品牌方关注重点调整五个维度的权重或增删子项
4. 如果是双平台分析，建议在维度二和维度三中明确拆分小红书/抖音的独立结论
5. 首次使用建议先用一周完整数据跑一遍，根据输出质量微调输入数据的颗粒度

## 模板设计理念

| 设计原则 | 说明 |
|---------|------|
| 数据事实先行 | 每个结论必须有数据支撑，避免主观臆断 |
| 归因不止于表象 | 不只说"涨了/跌了"，要说清楚"为什么" |
| 行动导向 | 每个维度最终落到"下一步做什么"，品牌方看完就能决策 |
| 隐私合规 | 不依赖评论明细/用户画像等隐私数据，仅使用公开汇总指标 |
| 双平台差异化 | 小红书与抖音的算法逻辑不同，分析和建议必须区分对待 |
