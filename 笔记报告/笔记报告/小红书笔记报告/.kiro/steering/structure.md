# Project Structure

```
小红书笔记报告/
├── .kiro/
│   └── steering/          # AI 辅助开发的引导规则
├── 矩阵笔记内容分析-提示词模板.md   # AI 分析提示词模板（核心工作流定义）
├── 小红书矩阵笔记分析报告.html      # 生成的可视化周报（HTML 单文件）
├── 2025年至今的全部笔记.xlsx        # 历史数据汇总
├── 20260510笔记.xlsx               # 周度原始数据
└── 20260519笔记.xlsx               # 周度原始数据
```

## 文件职责

| 文件类型 | 命名规则 | 用途 |
|---------|---------|------|
| 提示词模板 | `*提示词模板.md` | 定义 AI 分析的输入输出规范 |
| 周度数据 | `YYYYMMDD笔记.xlsx` | 单周原始运营数据 |
| 历史汇总 | `*全部笔记.xlsx` | 跨周期数据汇总 |
| 分析报告 | `*分析报告.html` | 最终输出的可视化报告 |

## 工作流

1. 收集本周 Excel 数据 → 放入项目根目录
2. 将数据填入提示词模板 → 交给 AI 分析
3. AI 输出 HTML 报告 → 保存为 `.html` 文件
4. 浏览器打开报告 → 交付品牌方

## 注意事项

- 报告为单文件 HTML，所有 CSS/JS 内联，无需构建工具
- Excel 文件命名需保持日期格式一致，便于识别周期
- 提示词模板是核心资产，修改需谨慎评估对输出质量的影响
